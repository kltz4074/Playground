# Unity Prototype Playground

Welcome! This repository is my personal Unity sandbox — a growing collection of prototypes, experimental mechanics, and technical concepts that I build while learning, testing ideas, and expanding my game development skills.

Here, I explore different systems, gameplay mechanics, and procedural generation techniques that may later become part of my future games :)

## Purpose

This project serves as:

- A playground for self-learning unity and programing  
- A collection of gameplay and technical prototypes  
- A learning space  

Some prototypes may stay as experiments, while others could evolve into full projects.

## Current Focus

I use this repository to:

- Test gameplay mechanics  
- Improve my Unity development skills  
- Experiment different mechanics  
- Build mechanics and ideas for my future projects
